Install

Set up in 3 steps

No package manager, no sudo, no dependencies to install. Self-contained.

1

Download for your OS

Pick Windows, macOS, or Linux above. The file is about 80–107 MB.

2

Install or run

Windows: Run the .exe installer, choose a folder, done.

macOS: Open the .dmg, drag Spyro Studio to Applications.

Linux: chmod +x *.AppImage && ./Spyro.Studio-*.AppImage

3

Start building

Launch Spyro Studio. The server starts locally on http://127.0.0.1:8791. Pick a provider, paste your key, and start building.

FAQ

Questions

Does it need an API key?

Spyro Studio is provider-agnostic. You bring your own key for a provider like OpenRouter, NVIDIA, Groq, or run a local model with Ollama. No Anthropic or Claude account is required.

Where are my files?

Everything stays on your machine. Conversations live in ~/.claude-free/sessions, and the workspace is ~/.claude-free/projects. Nothing is uploaded anywhere.

Is my code sent to the cloud?

Only to the model provider you choose, to run the AI. Your files, sessions, and keys are never sent anywhere by Spyro Studio itself.

Why is the installer so large?

It bundles Electron, the app UI, the Node server, and all runtime dependencies into one self-contained file — that is why it runs on any machine without installing anything first.

Is this open source?

No. Spyro Studio is free but closed-source. The binary is distributed as-is; the source is not published. Free forever does not mean open source.

How do I update?

Download the new release and replace the old file. Settings and sessions are kept in your home folder, so nothing is lost between versions.

Does it work offline?

The app runs entirely offline once installed. You only need an internet connection for the model provider you choose (or use Ollama for fully local AI).
