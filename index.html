Install

Set up in 3 steps

No package manager, no sudo, no dependencies to install. It is a single self-contained file.

1

Download the AppImage

Click the download button above, or fetch it directly:

$ wget https://github.com/lingzi3628-dot/claude-spyro/releases/download/v0.2.18/Spyro.Studio-0.2.16-x86_64.AppImage
2

Make it executable

AppImages are not executable by default. Add the permission once:

$ chmod +x Spyro.Studio-0.2.16-x86_64.AppImage
3

Run it

Double-click it, or launch from a terminal to see startup logs:

$ ./Spyro.Studio-0.2.16-x86_64.AppImage

FAQ

Questions

Does it need an API key?

Spyro Studio is provider-agnostic. You bring your own key for a provider like OpenRouter, NVIDIA, Groq, or run a local model with Ollama. No Anthropic or Claude account is required.

Where are my files?

Everything stays on your machine. Conversations live in ~/.claude-free/sessions, and the workspace is ~/.claude-free/projects. Nothing is uploaded anywhere.

Is my code sent to the cloud?

Only to the model provider you choose, to run the AI. Your files, sessions, and keys are never sent anywhere by Spyro Studio itself.

Why is the AppImage so large?

It bundles Electron, the app UI, the Node server, and all runtime dependencies into one self-contained file — that is why it runs on any Linux without installing anything first.

Is this open source?

No. Spyro Studio is free but closed-source. The binary is distributed as-is; the source is not published.

How do I update?

Download the new release and replace the old file. Settings and sessions are kept in your home folder, so nothing is lost between versions.
