Spyro Studio (Windows)
===========================

A free, provider-agnostic AI coding agent that runs entirely on your machine.

Install
-------
1. Unzip claude-free-spyro-<version>-win-x64.zip
2. Right-click install.ps1 -> "Run with PowerShell"
   (or: powershell -ExecutionPolicy Bypass -File install.ps1)
3. Run:  Spyro Studio.cmd

Requirements
------------
- Windows 10/11, Node.js 18+ (https://nodejs.org/)

Notes
-----
- Config, sessions and plugins live in %USERPROFILE%\.claude-free
- The agent cannot modify its own installation folder.
